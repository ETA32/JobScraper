This tool scrapes all jobs listed on Ziprecruiter, Salary.com, CareerExpert, and Career.com, with customizable conditions to separate out specific jobs while excluding others. 
It returns CSVs with all the Job information listed; title, annotated salary range, description, education and experience requirements, and more.

I primarily made this for my own use, and so I have not cleaned it up (yet) to be easily used by others. However, it does work perfectly fine. If you are looking to use it, simply replace the specific file names with your own and include their folder locations in a .env.
